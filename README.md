# SignalDesk

A seven-day portfolio and learning project. Day 1 is a local, deterministic conversation-ranking baseline; it needs **zero API keys and zero paid services**. All included conversations are synthetic.

## Run locally

Use Node 22.17.1 or a newer Node 22 release and npm. From this repository root in Git Bash:

```bash
npm ci
npm run dev
```

Open http://localhost:3000. Stop with Ctrl+C. In PowerShell, use `npm.cmd` if execution policy blocks `npm.ps1`; no policy change is required. Dependency installation requires internet access, but the application does not fetch data or fonts from external services. No environment file is needed.

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

`npm start` serves the completed build. `npm run test:watch` reruns unit tests during development. Run build and typecheck sequentially because both generate Next.js type files.

## Files

- `src/app/`: Next.js App Router page, root HTML layout, metadata, and Tailwind stylesheet.
- `src/data/sample.ts`: editable fictional company context, six conversations, and fixed scoring reference time.
- `src/lib/types.ts`: shared data contracts.
- `src/lib/ranking.ts`: framework-independent scoring baseline.
- `src/lib/ranking.test.ts`: behavior and edge-case tests.
- Root config files: TypeScript, ESLint, Tailwind/PostCSS, and Vitest.
- `AGENTS.md`: guidance generated by Next.js on development startup.
- `package-lock.json`: exact resolved dependency graph; use `npm ci` to reproduce it.

Next.js renders the ranking page using a Server Component. This static sample page can be prerendered during the build. Native HTML disclosure controls reveal explanations without a client-side state library. Future interactive workflows can introduce client components only when needed.
